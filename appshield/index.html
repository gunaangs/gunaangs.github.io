Privacy Policy for AppShield - Mobile App Scanner

Application: AppShield - Mobile App Scanner Developer: ANGS Corp Package: com.angs.appshield Last Updated: September 19, 2026

1. Overview & Privacy Commitment

Welcome to AppShield - Mobile App Scanner (“we”, “our”, or “the App”), developed and published by ANGS Corp.

AppShield is a standalone, offline mobile security scanner designed to inspect installed applications, evaluate heuristic risk scores, audit dangerous permissions, and detect sideloaded APKs. AppShield is architected strictly as a 100% on-device, zero-telemetry utility.

Zero-Server Architecture: All package scanning, heuristic risk calculation, and permission audits are executed locally on your device hardware. Your list of installed applications is never transmitted to, inspected by, or stored on ANGS Corp servers or any external third-party cloud.

2. Data Handled & Device Permissions

AppShield only accesses information strictly required to perform on-device security scans upon your request:

Permission / API How It Is Used Data Storage / Transmission
Package Visibility (QUERY_ALL_PACKAGES) Allows AppShield to enumerate installed applications and inspect package metadata (permissions requested, installer package name, signatures, target SDK). Never uploaded. Processed strictly in volatile device memory and discarded when the scan completes.
Storage Access (Read / Write) Used solely when you choose to export or save a generated security audit report (e.g. PDF or JSON format) to your local file system. Stored solely on your local device. ANGS Corp has zero access to saved audit reports.
Notifications Delivers on-device notifications when scheduled scans complete or critical permission changes occur. Operates completely on-device without remote push servers.

3. Third-Party Services

AppShield operates offline for all scanning functionality. The following third-party library is integrated with strict isolation:

Google Mobile Ads (AdMob)

  • AppShield may display advertisements provided by Google Mobile Ads.
  • Data Processed: Google may collect advertising identifiers, approximate IP location, and ad interaction metrics to deliver, personalize, and measure ads.
  • Consent Management: We implement Google's User Messaging Platform (UMP) to obtain explicit consent for personalized ads in compliance with GDPR and CCPA.
  • Strict Isolation: The Google Mobile Ads SDK runs in an isolated sandbox and has zero access to your installed application inventory, scan results, or audit reports.
