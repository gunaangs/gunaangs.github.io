Privacy Policy for AppShield: Mobile Security

Application: AppShield: Mobile Security (v3.0.0) Developer: Angs Corp Package: com.angs.appshield Last Updated: September 20, 2026

1. Overview & Privacy Commitment

Welcome to AppShield: Mobile Security (“we”, “our”, or “the App”), developed and published by Angs Corp.

AppShield is a standalone, local-first mobile security scanner, privacy auditor, and system optimization utility. It is designed to inspect installed applications, calculate heuristic risk scores, audit dangerous sensor and system permissions, detect sideloaded APKs, boost system memory, and clean residual junk files. AppShield is architected strictly as a 100% on-device, zero-telemetry utility.

Zero-Server Architecture: All package scanning, heuristic risk calculation, memory optimization, and permission audits are executed locally on your device hardware. Your list of installed applications and device telemetry are never transmitted to, inspected by, or stored on Angs Corp servers or any external third-party cloud.

2. Data Handled & Device Permissions

AppShield only accesses information strictly required to perform on-device security scans, privacy audits, and device maintenance upon your initiation:

Permission / API How It Is Used Data Storage / Transmission
Package Visibility (QUERY_ALL_PACKAGES) Allows AppShield to enumerate installed applications and inspect package metadata (permissions requested, installer package name, signatures, target SDK) for heuristic risk analysis and the Privacy Matrix. Never uploaded. Processed strictly in volatile device memory and local on-device SQLite database for trend reporting.
Memory Management (KILL_BACKGROUND_PROCESSES) Used locally by the RAM Booster to terminate idle background tasks and reclaim device memory when you initiate memory optimization. Never uploaded. Operates purely locally via the Android system process manager.
App Uninstallation (REQUEST_DELETE_PACKAGES) Enables the App to trigger the standard Android uninstallation prompt for flagged risky or sideloaded applications upon your confirmation. Never uploaded. Standard Android OS system intent.
Notifications (POST_NOTIFICATIONS & RECEIVE_BOOT_COMPLETED) Delivers on-device notifications for scheduled security audits, high-risk detection alerts, and scan reminders; reschedules local alarms after device reboot. Operates completely on-device via Android WorkManager without remote push servers.
Storage Inspection (Deep Cleaner & Residual Junk) Inspects storage directories strictly locally to identify temporary app cache, residual APK packages, and large files to help you reclaim storage space. Processed strictly on-device. Zero file contents or documents are read, uploaded, or transmitted off-device.
Advertising Identifier (AD_ID) Used exclusively by the Google Mobile Ads SDK (AdMob) to deliver advertisements and prevent invalid ad traffic, subject to user consent. Handled by Google Mobile Ads SDK in accordance with Google's Privacy Policy and UMP consent framework.

Google Mobile Ads (AdMob)

  • AppShield displays advertisements provided by Google Mobile Ads.

5. User Rights & Data Erasure

Because AppShield stores audit reports and preferences only on your device, you have complete control over all data:

  • In-App Reset: You can reset scan history, trusted apps whitelists, and cached data at any time directly in AppShield Settings.
  • Clearing Data: You can clear application cache and local scan history at any time via Android System Settings.
  • Uninstallation: Uninstalling AppShield permanently destroys all locally generated scan caches, settings, and files.
